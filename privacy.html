1. Behandlingsansvarlig

Sjøkart Norge drives av Øystein Frich. Kontakt: ofrich@hotmail.com.

2. Posisjonsdata

Appen kan bruke iPhone-posisjonen din for å vise din posisjon i kartet, samt fart, kurs, vær og relevante steder i nærheten. Posisjonsdata brukes når du gir appen tillatelse til dette. Posisjonen er først og fremst nødvendig for appens kart- og navigasjonsfunksjoner.

Appen er ikke ment som eneste navigasjonsmiddel, og brukeren er selv ansvarlig for sikker navigasjon og bruk av oppdaterte offisielle sjøkart og sjøvett.

3. Vær- og sjødata

For å levere vær-, vind- og sjøprognoser kan appen sende geografiske koordinater til eksterne vær- og sjødatatjenester. Disse koordinatene brukes for å hente prognoser for det valgte området.

4. Kart- og stedsdata

Appen kan hente kart- og geografiske data fra offentlige og andre tilgjengelige datakilder. Nettverksforespørsler kan innebære at tekniske data som IP-adresse behandles av leverandøren av den aktuelle tjenesten.

5. Brukerinnsendte bilder

Brukere kan velge å sende inn bilder knyttet til steder i appen. Innsendte bilder lagres i appens backend-tjeneste og er ikke offentlig synlige før de er gjennomgått og godkjent av eieren av Sjøkart Norge.

Ikke send inn bilder du ikke har rett til å dele, bilder som krenker andres personvern, eller annet ulovlig eller støtende innhold.

6. Backend og lagring

Sjøkart Norge bruker Supabase som teknisk backend for blant annet lagring og behandling av innsendt innhold. Data kan derfor behandles av Supabase som databehandler i samsvar med deres vilkår og sikkerhetsmekanismer.

7. Lokal lagring og offline-funksjoner

Appen kan lagre kartdata, favoritter, stedinformasjon, siste værdata og annet innhold lokalt på enheten for å kunne fungere helt eller delvis uten internett. Slike lokale data kan normalt fjernes ved å slette appen eller ved funksjoner i appen der dette tilbys.

8. Deling av personopplysninger

Sjøkart Norge selger ikke personopplysninger. Opplysninger deles bare når det er nødvendig for å levere appens funksjoner, oppfylle rettslige forpliktelser eller beskytte brukere og tjenesten.

9. Lagringstid

Data beholdes bare så lenge det er nødvendig for formålet. Innsendt innhold kan slettes eller avvises ved moderering. Ved henvendelse kan du be om innsyn, retting eller sletting av personopplysninger som kan knyttes til deg.

10. Dine rettigheter

Du kan kontakte oss for spørsmål om personvern eller for å be om innsyn, retting eller sletting. Kontakt: ofrich@hotmail.com.

11. Barn

Appen er ikke spesielt rettet mot barn, og vi ber ikke bevisst barn om å sende inn personopplysninger.

12. Endringer

Denne personvernerklæringen kan oppdateres når appens funksjoner eller databehandling endres. Oppdatert versjon publiseres på denne siden.
